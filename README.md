# 🚀 AscenDra Backend

ASCENDRA is an AI-powered Career Intelligence Platform that helps users discover career paths, analyze skills, generate roadmaps, and receive personalized recommendations for internships and learning.

This is the **FastAPI backend** that powers the intelligence engine of the platform.

---

# 🧠 Features

- 🔐 User authentication support (expandable)
- 🎯 Skill-based career matching engine
- 📊 Internship recommendation system (dynamic/future-ready)
- 🧭 Personalized learning roadmap generator
- 🤖 AI integration (Gemini / LLM-based assistant)
- 📚 Skill dataset processing system
- 🗂️ Profile + user data management
- ⚡ REST API for frontend integration
